# 记账

一款思源笔记记账插件。记录每日收支，支持自定义树形分类（账户）、统计、心情、星级评分、图片，以及 Daily Note 关联。

## 功能

- 记录每日收入 / 支出，支持自定义多级分类（账户）。
- 统计：汇总、分类占比、按月收支柱状图。
- Daily Note 关联：复用笔记本的系统日记模板路径，收支写入插件独占的记账明细子文档。
- 每笔记录可关联心情与多张图片（本地上传，或通过 forwardProxy 抓取外链图）。
- ZIP 导入导出（元数据与图片），兼容旧版 JSON 备份。

## 版本与授权

- **基础版免费**：记账、统计、分类与基础数据备份。
- **高级版**：图片关联、Daily Note 设置与同步、旧日记迁移、树洞气泡视图。
- 在插件「设置 → 版本与授权」复制本机码，向客服提供本机码取得授权码，再粘贴激活。
- [前往淘宝购买高级版](https://e.tb.cn/h.jQSAgko2SkQvsYg?tk=MRyu6dKwpDi)。授权期限以购买规格及实际签发授权码为准。
- 首次激活需要联网；每次加载插件只复查一次，后续功能调用读取内存授权状态。网络故障时，本地签名及有效期仍有效的已有授权可离线使用；明确过期、吊销或设备不匹配则锁定高级功能。
- 取消本机激活不会吊销授权码，也不会删除账目或已有图片；基础版仍可查看已有图片、编辑普通账目及导出备份。包含图片或日记关联设置的备份需激活高级版后恢复。
- 本机码来自持久化随机源的 SHA-256 摘要；授权数据单独保存，不包含在记账数据导出中。跨设备迁移需使用对应设备的授权。

## 安装

在思源集市中搜索“记账”并安装；也可以下载 GitHub Release 中的 `package.zip`，解压到 `工作空间/data/plugins/moneymanager/` 后重载插件。

## 开发

```bash
npm install
npm run dev     # 监听构建
npm run check   # 类型检查
npm run build   # 生产构建 + package.zip
```
