# 记账

在思源笔记里，记录每一笔收支，也留住消费背后的心情与生活片段。

「记账」将日常收支、分类统计和日记关联放在一起，让你既能看清钱花在哪里，也能回顾每一笔记录的意义。

## 主要功能

### 日常收支，轻松记录

- 记录收入与支出，填写日期、分类和备注。
- 使用计算器式金额输入，方便日常记账和修改记录。
- 按日、周、月、年或全部时间查看收支汇总。

### 自定义分类，账目更清楚

- 支持多级分类，按自己的习惯整理不同收支或账户。
- 在详情页按收支类型、月份筛选，搜索备注或分类，快速找到目标账目。
- 支持排序查看，方便梳理历史流水。

### 图表统计，看懂收支变化

- 查看收入、支出与结余，了解整体收支情况。
- 通过分类占比，了解主要收入来源和消费去向。
- 通过月度收支图，观察不同月份的变化。

### 心情与评分，记录不止金额

- 为每笔账目添加心情和星级评分。
- 配合备注，留下消费感受，方便日后回顾。

### 图片与日记，让账本融入生活

- **图片关联（高级版）**：为记录添加多张图片，留存票据、商品或生活照片。
- **日记关联（高级版）**：将当天收支写入思源日记，支持保存记录后自动同步。
- **树洞视图（高级版）**：用气泡浏览记录，按年月回顾，点击查看详情。

### 数据备份，方便留存

- 支持导出与恢复备份，方便保存账目或迁移数据。
- 支持包含图片的完整备份，兼容旧版备份。

## 免费版与高级版

| 版本 | 包含功能 |
| --- | --- |
| 基础版（免费） | 收支记账、多级分类、图表统计、心情与评分、账目筛选与搜索、基础数据备份 |
| 高级版 | 在基础版之上，增加图片关联、日记设置与同步、旧日记迁移、树洞气泡视图 |

基础版可直接使用；需要图片、日记联动等功能时，可按需升级高级版。

### 高级版激活

1. 打开插件「设置 → 版本与授权」，复制本机码。
2. [前往淘宝购买高级版](https://e.tb.cn/h.jQSAgko2SkQvsYg?tk=MRyu6dKwpDi)，向客服提供本机码，取得授权码。
3. 将授权码粘贴到插件中，联网完成首次激活。

授权期限以购买规格及实际签发的授权码为准。授权与设备绑定，更换设备前请先咨询客服。

## 安装与上手

1. 在思源集市中搜索「记账」，安装并启用插件。
2. 打开插件，按自己的习惯设置收支分类。
3. 录入第一笔收支，再到「详情」或「统计」查看账目。
4. 如需关联思源日记，激活高级版后，在设置中选择相应笔记本。

## 使用提醒

- 建议定期导出备份，尤其是在恢复数据、迁移旧日记或更换设备之前。
- 日记中的「💰 记账明细」子文档由插件维护，个人笔记请写在父日记中，避免后续同步影响手写内容。
- 取消本机激活不会删除账目和已有图片，仍可使用基础功能、查看已有图片及导出备份。
- 恢复包含图片或日记关联设置的备份，需要先激活高级版。
